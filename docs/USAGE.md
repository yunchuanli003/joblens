# 使用说明

## 1. 安装

1. 打开 `chrome://extensions/`（Edge：`edge://extensions/`），开启「开发人员模式」
2. 点「加载解压缩的扩展」，选择仓库根目录
3. 首次加载会打开设置页，填好画像后点「保存」

扩展只有在 `https://www.zhipin.com/*` 下才会注入面板；其他站点上它不运行，也不申请权限。

## 2. 画像七项

| 项 | 作用 | 建议 |
|---|---|---|
| 目标岗位概述 | 只用于展示，不参与打分 | 一句话写清方向 |
| 经验年限 | 同上 | 例如「3 年」 |
| 期望城市 | 换一批时用来改搜索条件 | 多城用逗号分隔 |
| 薪资下限（K） | 低于该值扣分 | 写月薪下限，不写年包 |
| HR 活跃度门槛（天） | 超过该天数未活跃直接标跳过 | 默认 14；填 0 关闭这项 |
| 偏好词 / 回避词 | 标题与正文命中即加减分 | 各写 5~10 个，越多越钝 |
| 标题核心词 | **只匹配标题**，命中才给高分 | 最容易漏的一项，务必填 |

标题核心词为空时，像「口腔医助」这类完全不相关的岗位也能拿到 30 分。设置页保存时会提醒这一点。

排除词分两层：

- **个人排除词**：只影响你自己的打分
- **通用排除词**（打分策略里）：所有岗位先过一遍，命中直接判跳过；默认含保险、贷款、中介、劳务派遣等

## 3. 扫描

1. 打开岗位列表页，例如 `https://www.zhipin.com/web/geek/jobs?query=EMC`
2. 点悬浮面板或 popup 里的「扫描打分」
3. 状态变成「扫描完成」后，卡片右上角会出现徽章

扫描过程只做三件事：读 DOM、向下滚动加载更多、给卡片打徽章。**不点击任何岗位卡**，也不会因此打开岗位详情或跳转页面；只有在滚动加载不出来时，才会对「加载更多 / 换一批」这类分页控件派发一次点击（点击前会排除落在岗位卡片与详情区的元素）。

## 4. 徽章

| 颜色 | 含义 | 阈值（默认） |
|---|---|---|
| 绿 | 推荐 | ≥ 62 分 |
| 橙 | 待看 | 42 ~ 61 分 |
| 灰 | 跳过 | < 42 分，或命中排除词 |

鼠标悬停在徽章上能看到打分理由，例如「标题命中 EMC；薪资 18-28K 达标」。

## 5. 换一批

列表页的岗位总量有限，扫完一批需要拉新的。点「换一批」后依次尝试：

1. 滚到底，触发无限加载
2. 点「加载更多」
3. 点「下一页」
4. 换搜索关键词 / 城市（会跳转，加载后自动重扫）

四招都到底了，面板会明确告诉你「这批到底了」，并给出改哪个条件的建议，而不是硬凑数量。

## 6. 报告与诊断

- **扫描报告**：点面板底部「报告」。纯文本，含每个岗位的分数、结论、命中理由，可直接复制给他人或存档。
- **页面诊断**：popup 底部「页面诊断」。导出真实 DOM 结构（卡片选择器命中情况、分页控件、详情区），选择器失配时先看这个。

## 7. 常见问题

**扫到 0 个岗位**
先看面板日志。三种典型原因：不在列表页（在详情页/聊天页）、未登录、站点改版导致选择器失配。报告最后一行会给出对应的诊断，页面诊断能进一步定位。

**薪资显示成乱码或 111-111K**
站点把薪资数字映射到私用区字符。到设置页「高级 → 薪资字体映射」按实际顺序改这 10 位数字；识别不出来时报告里会标「薪资存疑」，不参与打分。

**徽章挡住按钮**
徽章是 `pointer-events:none`，不会挡住点击。若确实妨碍阅读，点「扫描打分」重新扫描或刷新页面即可清除。

**面板找不到**
面板在右下角，点标题栏的「–」可折叠。若被其他浮层盖住，刷新页面会重新挂载。

**扩展更新后没生效**
`chrome://extensions/` 里点扩展卡片上的刷新按钮，然后刷新目标页面。
